# AI Trading Agent

A simple AI-powered trading assistant for Base and Ethereum. This agent helps support some simple activities to manage your crypto portfolio, analyze holdings, and execute trades using natural language commands.

## Features

- **Portfolio Tracking**: View token balances, values, and distribution across multiple chains (Ethereum, Base, & Sepolia currently)
- **AI Chat Interface**: Natural language interaction for trading and portfolio insights
- **Trading Execution**: Buy and sell tokens using the 0x Protocol on Base chain

## Usage

1. Connect your wallet or enter a public address to view in read-only mode
2. Use the chat interface to interact with the trading agent
3. View your portfolio, analyze holdings, and execute trades
4. Use the command shortcuts in the toolbar for quick access to common commands
